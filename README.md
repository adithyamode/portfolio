# Premium Full-Stack + DevOps Portfolio

A production-style React + TypeScript portfolio designed to position the owner as a **Full-Stack Engineer & DevOps Engineer**, while using the portfolio itself to demonstrate frontend engineering.

## Stack
- React + TypeScript
- Vite
- Tailwind CSS
- Framer Motion
- Lucide React

## Run locally
```bash
npm install
npm run dev
```

## Production build
```bash
npm run build
npm run preview
```

## Before publishing
Replace all `[Add ...]` placeholders in `src/data/portfolio.ts`, add your real `public/resume.pdf`, and update external links. Do not publish internal company details or confidential project information.

## Deployment
### Vercel
Import the repository. Build command: `npm run build`. Output directory: `dist`.

### Netlify
Build command: `npm run build`. Publish directory: `dist`.
